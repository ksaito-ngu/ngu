学びの軌跡NOTE の抽出データ（フィードバック付き）から、学生ごとの面談質問リストと「面談で押さえる点」CSVを作成して。

## 引数
`$ARGUMENTS`: `<PDFフォルダ>`
- `/portfolio-feedback` を実行済みのフォルダ（中に `抽出データ_FB/` があること）

例:
- `/mendan-questions 学び\30`
- `/mendan-questions 学び\29`

## 手順

### Step 1: 入力の確認
- `<フォルダ>/抽出データ_FB/*.md` を読む（なければ先に `/portfolio-feedback` を実行するよう伝えて終了）
- 各mdから、GPA・出席率・成長目標DP・振り返り・目標・相談・アドバイザーのコメント・フィードバックを把握する
- どの時期の記入か（例：9〜11ページ＝1年次春の振り返りと秋の目標、15〜17ページ＝1年次の振り返りと2年次春の目標）を確認し、面談の対象時期（例：1年次秋学期）を決める

### Step 2: 質問を考えて questions.json に書く
`<フォルダ>/面談質問リスト/questions.json` を次の形で作る（既にあれば上書きしてよいか確認する）:

```json
{"学年": "30B", "対象": "1年次秋学期", "ページ": "9〜11",
 "students": {
  "0003": {"要点": "記入内容の要約（1〜2文）",
           "押さえる点": "面談で特に確認したい点（CSVに出す。読点区切りで1行）",
           "1": ["GPA・出席率の確認の質問", "..."],
           "2": ["達成できたこと"], "3": ["達成できなかったこと"],
           "4": ["今学期の行動目標"], "5": ["資格取得の計画"], "6": ["インターンシップ・将来"],
           "確認": ["確認事項・相談への回答"]}}}
```

- キーは学籍番号の下4桁（mdファイル名の先頭4桁）。全員分を作る
- 1人 9〜14問。6ステップは面談アプリ（`/mendan`）と同じ並び
- 質問の方針:
  - 数値（GPA・目標GPA・出席率）は記入値をそのまま使い、目標に対する結果を聞く
  - 本人の記述（資格名、アルバイト先、留学、サークル、苦手なこと）を具体的に取り上げる
  - はい／いいえで終わらない、話を引き出す聞き方にする。責める言い方はしない
  - 記入時期より後の出来事（試験、夏休みの計画など）は「どうなったか」を聞く
  - **相談欄に書かれたことは「確認」に【相談への回答】として必ず入れる**
  - 次の学生は「確認」と「押さえる点」に明記する：
    - アドバイザーのコメントが未記入（初めての面談になる）
    - 成長目標DPが「選択」のまま（面談中に決めて記入してもらう）
    - GPAが低い（2.0未満）・単位を落とした（学習支援の窓口の案内、生活面の確認）
    - 目標GPAが実情とかけ離れている（当面の目標を提案）

### Step 3: ファイルを生成する
```bash
cd <manabi-note のフォルダ>
PYTHONIOENCODING=utf-8 python py/make_mendan_questions.py "<フォルダ>"
```

出力:
- `<フォルダ>/面談質問リスト/<4桁>_<氏名>_面談質問.md` … 冒頭の表（GPA等・要点）、6ステップの質問と確認事項、面談で伝えること（フィードバック）、面談メモ欄
- `<フォルダ>/面談質問リスト/<学年>_面談質問リスト_全員.md` … 全員分（印刷・通し読み用）
- `<フォルダ>/<フォルダ名>_面談で押さえる点.csv` … 学籍番号・氏名・面談で押さえる点（BOM付きUTF-8）

### Step 4: 結果表示
- 学生ごとの問数と、特に注意が必要な学生（上の4条件に当たる学生）を表にして示す

## 注意
- 質問を直したいときは questions.json を直して Step 3 を再実行する（mdを直接直すと次の生成で消える）
- 実績：学び/29（7名、15〜17ページ）・学び/30（11名、9〜11ページ）を2026-10-06に作成
