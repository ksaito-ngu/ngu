学びの軌跡NOTE（PDF）からデータを抽出し、各学生へのフィードバックコメントを生成して。

## 引数
`$ARGUMENTS` は最大3つ:
1. **PDFフォルダ**: 学びの軌跡NOTE PDFが入ったフォルダパス
2. **対象ページ**: データ抽出するページ番号（カンマ区切り、省略時は `9,10`）。**学期名でも指定できる**:

   | 書き方（どれでも可） | 29B様式（45ページ） | 30B様式（36ページ） |
   |---|---|---|
   | `1年春` `1春` `1S` `1年前期` `Ⅰ春` `一年春` | 9, 10, 11 | 9, 10 |
   | `1年秋` `1秋` `1A` `1年後期` `Ⅰ秋` `一年秋` | 12, 13, 14 | 11, 12 |
   | `2年春` `2春` `2S` `2年前期` `Ⅱ春` `二年春` | 15, 16, 17 | 13, 14 |
   | `2年秋` `2秋` `2A` `2年後期` `Ⅱ秋` `二年秋` | 18, 19, 20 | 15, 16 |
   | `3年春` 〜 `4年秋` | 21〜32（3ページずつ） | 17〜24（2ページずつ） |

   - **ページは固定ではなく、PDFごとに自動で決まる。** 各学期のシートの先頭ページの1〜2行目に、黄色背景で「1年次春学期分」「1年次秋学期分」…が昇順に入っているので、その見出しのページから次の見出しの直前までを、その学期のページとする（`py/extract_portfolio.py` の `semester_map`）。学年によって様式が違っても、同じ指定で正しいページを読む
   - 「◯年次◯学期分」のシートには、**直前の学期の結果・振り返り**と**その学期の目標**が入っている（例：「1年次秋学期分」＝1年春のGPA・振り返り＋1年秋の目標）
   - 学年は算用数字・ローマ数字（Ⅰ〜Ⅳ）・漢数字（一〜四）のどれでもよい。学期は 春／S／前期／Spring、秋／A／後期／Fall／Autumn（大文字・小文字は問わない）
   - 英語の書き方も可：`1Fall` `1 Autumn` `2 Spring` `1st year Fall` `Year 1 Fall`
   - 全角（`２年秋`、`１Ｓ`）や読点（`17、18、19`）、スペース入り（`18, 19`）も可。数字で指定したときは、そのページをそのまま読む（様式による違いは考慮しない）
3. **文字数**: フィードバックコメントの目安文字数（省略時は `300`）

※ ページ1（学籍番号・氏名等の基本情報）は常に読み取る（固定）。

例:
- `/portfolio-feedback 学び\30` → ページ9,10、300字
- `/portfolio-feedback 学び\30 9,10 500` → ページ9,10、500字
- `/portfolio-feedback 学び\30 1年春 400` → 1年春のページ（29B様式は9〜11、30B様式は9〜10）、400字
- `/portfolio-feedback 学び\29 2S 400` → 2年春のページ（29B様式は15〜17）、400字

### 学期名の解釈と表示
- 学期名で指定されたときは、PDFごとに何ページとして扱ったかを表示する（抽出結果の「OK: … (ページ18,19,20, …)」）
- 抽出は `--pages` にそのまま渡してよい（`extract_portfolio.py` が学期名を解釈する）

### PDFファイルが1件だけ指定されたとき
- フォルダ全体の既存結果（`抽出データ/` など）を上書きしないよう、`<フォルダ>/分析_<開始>-<終了>/`（例：`分析_18-20`）を作り、そこにPDFをコピーして処理する
- 同じページ範囲の別の学生が追加されたら、同じ `分析_…` フォルダに追加する

## 手順

### Step 1: PDFフォームフィールド抽出
指定フォルダ内の全PDFファイルについて、PyMuPDF（fitz）でフォームフィールドを読み取る。

```bash
cd <manabi-note のフォルダ>
PYTHONIOENCODING=utf-8 python py/extract_portfolio.py "<フォルダ>" --pages <対象ページ>
```

例: `python py/extract_portfolio.py "学び\30" --pages 9,10`

`py/extract_portfolio.py` がない場合は以下の仕様で作成する:

各PDFから以下を抽出:
- **ページ1（固定）**: `学籍番号`, `名前`, `基礎ゼミ教員名`, `アドバイザ1、2年` 等の基本情報
- **指定ページ（可変）**: そのページにあるすべてのフォームフィールド（値が入っているもの）

出力:
- フォルダ内に `抽出データ/` サブフォルダを作成
- 各学生ごとに `<学籍番号>_<氏名>.md` として保存
- 同一学籍番号が複数あれば後のファイルで上書き（最新版採用）

Markdownの構造:
```
# 学びの軌跡NOTE - <氏名>(<学籍番号>)

## 基本情報
- 学籍番号: ...
- 氏名: ...
- アドバイザ1、2年: ...

## ページ9・10の記入内容

### Q1. 最も意欲的に成長を目指したいDP
...

### Q2. 春学期の具体的な行動目標
...

### Q3. 卒業までの長期目標
...

### Q4. アドバイザー教員への相談事
...
```

### Step 2: フィードバックコメント生成
抽出した各学生のmdファイルを読み、記述内容に基づいて **指定文字数程度**（デフォルト300字）のフィードバックコメントを生成する。

フィードバックの方針:
- 学生の記述の良い点を具体的に認める
- 目標達成に向けた実践的なアドバイスを1〜2点添える
- 相談事があればそれに応える一言を含める
- 温かく励ます口調で、ですます調
- 学生の具体的な記述（資格名、留学、サークル等）に言及する

### Step 3: CSV出力
フィードバック結果をCSVファイルとして保存する。

| 列 | 内容 |
|----|------|
| A | 学籍番号 |
| B | 氏名 |
| C | フィードバックコメント（指定文字数程度） |

- 出力ファイル名: `<フォルダ名>_フィードバック.csv`
- エンコーディング: BOM付きUTF-8（Excel文字化け防止）

### Step 4: フィードバック付きMD出力
抽出データの各mdファイルにフィードバックコメントを追加したバージョンを作成する。

- 出力先: `<PDFフォルダ>/抽出データ_FB/`
- 元の `抽出データ/` のmdファイルをコピーし、末尾に以下を追加:

```markdown

## アドバイザー教員からのフィードバック

<フィードバックコメント>
```

- CSVの学籍番号とmdファイル名の先頭4桁をマッチングして対応づける
- 元の `抽出データ/` は変更しない

### Step 5: 結果表示
完了後、各学生のフィードバックを表示する。
続けて面談の準備をする場合は `/mendan-questions <PDFフォルダ>` で学生ごとの面談質問リストを作れることを案内する。

## 注意事項
- フォームフィールドが空のPDFはスキップする
- ページ数がPDFによって異なる場合は、フィールド名で検索する（ページ番号に依存しない）
- 依存: PyMuPDF（`pip install pymupdf`）
